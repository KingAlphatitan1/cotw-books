# COTW Books

Home for J. Nathaniel book manuscripts, including the Chronicles of the Wicked multiverse.

## What goes here
- Manuscripts by draft and version (never overwrite a prior draft)
- Canon notes, character bibles, and series outlines
- KDP publishing checklists and release notes

## Filing rules
- Every rewrite gets its own dated version; fix by sequencing, never by deleting
- This is high value IP. Private only, always. No public repos, no shared links without explicit approval.
